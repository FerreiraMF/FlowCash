# 💰 FlowCash

FlowCash é uma aplicação web de controle financeiro desenvolvida com HTML, CSS e JavaScript.

O projeto permite cadastrar receitas e despesas, acompanhar o saldo e manter as transações salvas mesmo após atualizar ou fechar a página.

## 🖥️ Preview

![FlowCash](https://raw.githubusercontent.com/FerreiraMF/FlowCash/refs/heads/main/assets/desktop.png)

## 🚀 Funcionalidades

- Adicionar receitas e despesas
- Excluir transações
- Cálculo automático de receitas, despesas e saldo
- Persistência de dados com LocalStorage
- Identificação única das transações com UUID
- Formatação de valores em Real brasileiro (BRL)
- Layout responsivo para dispositivos móveis
- Diferenciação visual entre receitas e despesas

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git e GitHub

## 📚 O que aprendi

Durante o desenvolvimento do FlowCash, pratiquei conceitos como:

- Manipulação do DOM
- Arrays e objetos
- `filter()`, `forEach()` e `findIndex()`
- Eventos com `addEventListener()`
- Persistência de dados com `localStorage`
- `JSON.stringify()` e `JSON.parse()`
- Uso de `crypto.randomUUID()`
- Formatação com `toLocaleString()`
- Flexbox
- Media Queries
- Organização de commits com Git

## 📱 Responsividade

O FlowCash foi desenvolvido para funcionar tanto em computadores quanto em dispositivos móveis.
